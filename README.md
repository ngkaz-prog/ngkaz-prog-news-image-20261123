Sum up 23 November's world news in one image.

`main.ts` copies `entry.png` to `/output/entry.png`. The image is a
newspaper front page drawn fresh for this entry: COP31 collapses in
Antalya, Ukraine sinks a Russian warship at Benghazi, Russian strikes
kill 11 near Kyiv, drones hit a UN building in Khartoum, a factory fire
kills 24 in Indonesia — plus BepiColombo at Mercury and Nvidia
reinstating Jensen Huang.

## Run it

```sh
node main.ts
```

Run it with `MAKEFUN_OUTPUT_DIR` set to write somewhere else.
